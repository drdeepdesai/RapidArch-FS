# RapidArch FS — Free Suite

The **free desktop 3D suite for dentistry**, from [RapidArch](https://rapidarch.com).

View, measure, align, and edit STL · PLY · OBJ — occlusion heatmaps, scanbody swap, engraving, slicing, format conversion, and QC report PDFs. Windows 10/11, no account, works offline, **free forever**.
